# khw-dev.github.io

개인 포트폴리오 [khw.dev](https://khw.dev)의 소스 코드입니다.

> Svelte, TypeScript, SCSS, Vite & GitHub Pages

## How to run

Node.js 22와 pnpm 10.33.0을 사용합니다.

```sh
pnpm install
pnpm dev
```

빌드 결과는 아래 명령으로 확인할 수 있습니다.

```sh
pnpm build
pnpm preview
```

## Publishing

`main` 또는 `master` 브랜치에 push하면 GitHub Actions가 빌드한 `dist`를 GitHub Pages에 배포합니다.
